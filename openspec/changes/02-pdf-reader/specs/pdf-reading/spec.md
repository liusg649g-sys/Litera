# Spec Delta

## Purpose

让用户在线阅读自己的 PDF 文献并维护可跨会话恢复的科研标注与阅读进度，向后续翻译、笔记和智能问答提供明确的物理页码、选中文本及位置上下文。

## ADDED Requirements

### Requirement: 在线阅读与导航
系统 SHALL 渲染本人有效 PDF，并支持翻页、缩放和目录跳转；页码使用从 1 开始的物理页面，遇缺少目录或不可读文件必须有明确反馈。

#### Scenario: 阅读与目录跳转
- **WHEN** 用户打开有效 PDF 并翻页、缩放或选择目录节点
- **THEN** 显示对应页面，页码/缩放状态与可见文献一致

#### Scenario: 无目录或读取失败
- **WHEN** PDF 无目录，或文件损坏/加密而暂不支持读取
- **THEN** 无目录显示空状态，读取失败显示明确原因与重试/返回入口，不伪装渲染成功

### Requirement: 全文搜索与文本选择
系统 SHALL 在 PDF 可用文本中全文搜索并跳转匹配位置，允许选择原文且提供当前文献、页码和选区位置；无可提取文本须明确说明。

#### Scenario: 搜索及选择
- **WHEN** 用户搜索文中关键词并选择包含匹配结果的一段原文
- **THEN** 可跳转匹配页，输出实际选中文本及与页面关联的位置，多页选区按页表达

#### Scenario: 无文本 PDF
- **WHEN** 用户在扫描版无文本 PDF 中搜索或选择文字
- **THEN** 提示文本不可用，不生成虚构选区或假搜索结果

### Requirement: 标注新增修改删除与恢复
系统 SHALL 允许本人文献的高亮、下划线、书签与批注新增、内容/颜色修改和删除，持久化后重开及改变缩放/旋转仍能恢复到对应原文位置。

#### Scenario: 标注完整生命周期
- **WHEN** 用户创建各类标注、修改批注、删除其中一个并重开文献
- **THEN** 已保存标注正确恢复，已删除标注不出现，页面书签可导航

#### Scenario: 保存失败或版本冲突
- **WHEN** 标注写入失败或提交陈旧 version
- **THEN** 显示失败/409 冲突，保留本地未保存输入，不标记为已持久化

#### Scenario: 缩放与旋转恢复
- **WHEN** 用户改变缩放比例或页面旋转后重新查看已有高亮
- **THEN** 标注仍覆盖同一原文区域，不使用固定屏幕像素造成偏移

### Requirement: 阅读进度持久化
系统 SHALL 保存本人文献的当前物理页、缩放与最近阅读时间，重开恢复最近已成功保存的进度，并阻止旧版本覆盖更新状态。

#### Scenario: 重开阅读
- **WHEN** 用户保存第 N 页的进度后关闭并重开文献
- **THEN** 恢复该页和已保存缩放，最近阅读反映真实访问

#### Scenario: 旧进度或非法页码
- **WHEN** 提交陈旧 version 或超出 PDF 页数的页码
- **THEN** 返回 409 或 422，不覆盖有效进度

### Requirement: 阅读数据权限边界
系统 SHALL 对 PDF、标注和进度逐次校验当前用户及文献关联；已删除文献和跨文献标注不可作为有效操作目标。

#### Scenario: 越权或错关联
- **WHEN** 用户读取他人 PDF，或把文献 A 的 annotationId 提交到文献 B
- **THEN** 返回 404，不暴露内容或改变标注/进度

#### Scenario: 文献进入回收站
- **WHEN** 已打开文献被软删除后继续请求内容、标注或进度
- **THEN** 拒绝后续访问并提示文献不可用，保留服务端数据用于恢复
