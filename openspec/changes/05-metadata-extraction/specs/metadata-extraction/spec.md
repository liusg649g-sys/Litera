# Spec Delta

## Purpose

将用户私有 PDF 转化为可人工校正的题录候选和带物理页码的正文证据，向下游问答提供原子发布的版本化页文本及片段，同时保持已上传文件和人工题录的可靠性。

## ADDED Requirements

### Requirement: 提取任务与状态
系统 SHALL 在模块启用后接受本人有效文献的提取请求，提供 queued、processing、completed、failed 状态及可查询任务；相同文件版本的重复请求不得产生重复活动任务。

#### Scenario: 启用后的提取请求
- **WHEN** 用户对本人已上传文献发起提取
- **THEN** 返回可查询作业，状态随实际处理变化，不阻塞原文献查看

#### Scenario: 重复请求或处理重启
- **WHEN** 同文件版本重复请求或工作进程中断后恢复
- **THEN** 幂等返回/恢复作业，不发布重复或不完整结果

### Requirement: 题录字段候选
系统 SHALL 输出题名、作者、摘要、关键词、年份、期刊和 DOI 候选，并允许未知字段为 null 或空数组；低置信度或缺失字段必须明确提示，不伪造信息。

#### Scenario: 可提取元数据
- **WHEN** PDF 中存在可识别题录
- **THEN** 输出规范字段及可用来源页/置信信息，保留未知项的明确状态

#### Scenario: 部分字段缺失
- **WHEN** 文献缺少 DOI、年份或其他字段
- **THEN** 返回未知值与提示，不用猜测值补齐

### Requirement: 正文页码与分块契约
系统 SHALL 提供 documentId、fileHash、extractionVersion、按物理页排序的正文和单页文本分块，片段包含稳定标识、页码与页文本偏移；结果完成后才可供下游读取。

#### Scenario: 下游读取完整版本
- **WHEN** 提取成功且下游读取完成版本
- **THEN** 每片段可映射到同版本页文本与原始 PDF 物理页，返回内容完整一致

#### Scenario: 处理尚未完成
- **WHEN** 下游请求未完成版本
- **THEN** 返回未就绪状态，不暴露部分 pages/chunks 作为完整证据

### Requirement: 人工校正与手工题录保护
系统 SHALL 将自动题录作为候选呈现，用户明确选择后通过正式题录更新契约保存，不自动覆盖现有人工字段；校正不得改变原 PDF。

#### Scenario: 接受候选字段
- **WHEN** 用户选中候选中的标题/作者等字段并提交当前 version
- **THEN** 仅所选正式题录字段更新，未选字段及原 PDF 保持不变

#### Scenario: 提取晚于手工修改
- **WHEN** 用户手工修改后提取结果才完成
- **THEN** 展示候选但不覆盖新题录；旧 version 提交返回 409

### Requirement: 提取失败与不可解析反馈
系统 SHALL 对损坏、暂不支持加密、无可提取文本及服务超时提供明确错误/警告和可重试状态；失败不能回滚已成功上传文件或伪造供 RAG 使用的正文。

#### Scenario: 扫描 PDF 无文本
- **WHEN** PDF 不含可提取文本且当前未启用 OCR
- **THEN** 提示正文不可用，保留文献，问答不能将其标记为可检索正文

#### Scenario: 超时后重试
- **WHEN** 提取超时后用户重试
- **THEN** 显示失败原因并重新进入受控作业流程，保留此前有效结果直到新版本完成

### Requirement: 提取权限与文献删除
系统 SHALL 在提交、查询和执行任务前验证文献归属与可用状态，软删除阻断新结果访问，永久删除清理提取及其派生数据。

#### Scenario: 越权查询或触发
- **WHEN** 用户请求他人文献/作业或指定非法文件目标
- **THEN** 返回 404，不读取该文件或执行解析

#### Scenario: 在途任务遇删除
- **WHEN** 文献在解析期间被删除
- **THEN** 停止或拒绝发布可访问结果，结果不能重新激活已删除文献
