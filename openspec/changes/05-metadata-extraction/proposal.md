# Proposal

## Why

上传 PDF 的手工题录需要可校正的自动提取候选，AI 问答则需要可靠的页文本和可引用片段。提前约定提取版本、失败状态和元数据写入边界可避免错误覆盖用户信息。

## What Changes

- 规划题名、作者、摘要、关键词、年份、期刊和 DOI 的提取候选。
- 规划 PDF 正文/物理页码、单页分块、任务状态和可重试失败。
- 规划人工选择候选，经 01 统一元数据更新契约提交；向 06 发布版本化正文。
- 本次不实现 PyMuPDF、后台作业、OCR 或自动供应商调用。

## Capabilities

### New Capabilities

- `metadata-extraction`: 文献题录候选、版本化页文本/分块、人工校正与提取生命周期。

### Modified Capabilities

无；复用 01 的上传扩展点与正式题录更新接口。
