# Proposal

## Why

05 已交付版本化页文本与分块，网关也已实测可用 `course-chat`（对话）和 `course-embedding`（2048 维向量）；06 目前仍只有规划。用户需要在阅读当前文献时获得摘要、研究结构解析和可核对出处的问答，并且必须能识别"本文没有这个信息"，避免把模型输出当成已验证事实。

## What Changes

- **单文献 RAG 问答**：只针对当前用户、当前文献、当前提取版本检索；向量与 BM25 混合召回，服务端把检索片段编号后交给模型，模型只回答"用了第几号片段"，不自行编写原文或页码。
- **摘要与结构解析**：一次模型调用输出摘要和研究背景、研究方法、主要结果、研究结论四部分解析；每部分必须带引用，缺失部分明确写"未找到对应证据"；同一提取版本结果可复用。
- **引用核验**：引用包含 documentId、extractionVersion、chunkId、服务端截取的 quote 和物理 pageNumber；模型编号越界、片段不属当前文献或有效引用为零时降级为证据不足，不发布假引用。
- **问答历史持久化**：新增 qa_answers，保存问题、答案、引用、版本和 answerId，供历史回溯与 04 保存笔记解析。
- **索引与版本**：新增 qa_indexes / qa_chunk_vectors 派生表；提取版本完成后后台批量 embedding，就绪后原子切换活动索引；未就绪返回 503，旧索引保留以便旧回答引用可核对。
- **同步问答接口**：`POST /documents/{id}/qa` 同步返回；未就绪/索引构建中 503、模型超时 504、限流 429，沿用统一 error 包络。
- **AI 阅读助手三态界面**：展开时 PDF 为主、右侧 500px 助手面板（机器人与标题欢迎区、分类标签与单行建议问题、底部输入框与发送、圆形收起按钮）；与翻译或笔记同时展开时，扩展面板参与布局、PDF 变窄但完整可见，不被任何面板覆盖；收起后 PDF 恢复原宽度，左下角悬浮胶囊，点击恢复。面板复用 02 的 ReaderContext 与 Citation 契约。
- **建议问题与发送**：只保留四个分类标签与一行建议问题（点击填入输入框、由用户确认发送）以及"发送"按钮；不再提供文献速读、核心创新、研究方法、研究结论快捷按钮，也不提供划词提问、当前页提问、快捷总结。summary/analysis 接口与缓存保留，但 UI 不设快捷入口，任何入口都不伪造结果。
- **引用折叠与消息定位**：答案中的原文引用默认折叠为"原文引用（N）"，用户展开后显示页码徽标与 quote，页码仍可跳转；每次发出新问题以及答案/错误到达时，消息区自动定位到该条问答处。
- **04 接入**：实现 `QaAnswerResolver`，用真实 qa_answers 替换 `UnavailableAnswerResolver`，笔记保存链路无需改动。

**不做**：跨文献全库问答、PDF 截图/视觉理解、多轮会话、SSE 流式输出、引入外部公开文献作为证据、外部向量数据库。

## Capabilities

### New Capabilities

- `document-qa`: 当前私有文献的摘要与结构解析、混合检索问答、服务端引用核验、证据不足反馈、问答历史与助手面板三态交互。

### Modified Capabilities

无。阅读器布局壳、ReaderContext 与 Citation 契约由 02 提供，正文与分块由 05 提供，笔记写入契约由 04 提供；本 change 只新增问答行为和助手面板组件。
