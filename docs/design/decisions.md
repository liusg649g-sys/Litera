# 设计建议与待确认项

## 重要建议（交付评审时确认，未开始实现）

| 编号 | 建议 | 理由/替代 |
| --- | --- | --- |
| D1 | 同源 Nginx + 服务端 Cookie 会话；密码 Argon2id | 真实退出可撤销、PDF 请求方便；相比浏览器持久 JWT 降低前端凭证管理复杂度 |
| D2 | 每用户私有库；不含群组共享/管理员 | 已给需求明确普通用户与数据隔离；“协作”暂按开发协作解释 |
| D3 | 重复以同用户 PDF SHA-256 判断，含回收站；跨用户不提示重复 | 避免泄漏其他人的文件；相同 DOI/题名提示不作为首版阻断规则 |
| D4 | 单层文件夹、文献最多一个文件夹，多个标签；删除文件夹后文献归未分类 | 满足基础分类；多级树和多文件夹需独立规格更新 |
| D5 | 显式永久删除，不做定时清空；软删除保留文件、标注和笔记 | 恢复完整关联；具体保留期目前不增加复杂规则 |
| D6 | 一次只展开一个右侧活动面板，AI 收起后显示悬浮入口 | 保留截图核心交互，避免三栏挤压阅读区域 |
| D7 | MySQL 页文本/分块作为证据真源，向量索引可重建；只针对当前文献 | 便于权限/版本一致性；后续替换向量后端不改变 DTO |

上述为可评审的首版设计，不声称用户已经认可。若调整 D1–D7，先修订相关公共文档与 change，再执行实现。当前任务有明确规划范围，无需为了生成设计提前选择外部服务商。
