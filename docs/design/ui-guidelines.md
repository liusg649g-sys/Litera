## 视觉与反馈

品牌 Litera，中文名“科研文献智能管理与协作平台”。主题变量：`--brand-primary: #9B0000`、`--surface: #FFFFFF`、`--page-bg: #F7F8FA`、`--border: #E5E7EB`、`--text: #303133`。选中状态用文字/小区域品牌色，背景主要白/浅灰。字体使用系统中文无衬线；正文建议 14px，清晰行距，简洁边框与少量阴影。图标统一选择 Element Plus Icons 或 Lucide，最终库见待确认表。

登录页品牌+表单，不使用大红铺底；各控件有标签、键盘焦点和错误提示，错误不只靠颜色。通用状态：loading、empty、error/retry、ready；异步失败保留用户输入。功能未就绪时隐藏或显示“待实现”说明，不发起伪服务请求。

Logo 与顶部品牌栏的英文文字统一为 `Litera`；中文产品名保持不变。浏览器页面标题按“Litera · 登录”“Litera · 注册”“Litera · 文献库”“Litera · PDF 阅读器”命名，阅读器文献标签仍显示文献题名。自有品牌图标沿用现有设计要求。

## 页面与路由

P2-A使用Element Plus Icons，顶部品牌/用户栏+左侧导航+中央表格/分页；默认导航240px，拖动或键盘箭头受限180–320px，按钮折叠56px并保留图标/提示，重新展开恢复本页宽度。宽度偏好暂在组件内存，退出/离开清理，不持久化到localStorage；用户级本机持久化留给后续布局优化。窄屏默认折叠，可打开覆盖式导航，表格仅自身横向滚动，操作列固定右侧。颜色沿用集中Token。

P2-A启用本地PDF导入、真实列表/基础排序/分页、右侧文献信息/题录编辑面板、浏览器预览及下载。作者/关键词编辑每行一项。保存失败保留草稿，版本冲突需确认放弃草稿并载入最新版；列表失败提供重试，未读配置时禁止导入。P2-B导航标待实现，仅说明而不请求对应业务；不放假搜索输入或假标签数据。/reader/:documentId返回原ID详情与待实现说明。

## P2-A 文献库交互优化

本轮仅前端交互，API/数据库结构及业务规则不变。主表格六列：原文标题、作者、发表年份、期刊、标签、操作。标题分配更多宽度；主要文本单行省略，溢出时才显示统一白色浅灰边框圆角轻阴影Element Plus Tooltip，无原生title。表头约44px、行约48px，横向滚动，右侧操作固定。每行阅读（真实浏览器预览，提示阅读器待实现）/详情/更多；更多菜单仅编辑题录信息与下载PDF，点击外部关闭，teleport至body，不设列设置。

信息面板默认360px，可调320–520px；中央区保留560px宽度，按可用区域不足320+560切换覆盖抽屉。桌面打开占用右侧布局宽度，关闭恢复表格；同一组件在窗宽变化时保留草稿，快速切换的旧响应不注入新文献。面板按题录、摘要关键词、标签、文件信息分组；空值统一“未填写”；只有已有题录字段可编辑。关闭、切换、取消编辑及普通路由离开时如有修改需确认；保存中禁关闭，失败保留内容，CAS冲突载入新版先确认。抽屉具对话框语义、背景inert、焦点约束、Escape关闭与焦点恢复；浏览器刷新未保存时使用离页保护。

未保存确认采用面板内部局部浮层，遮罩只覆盖文献信息面板。确认卡宽88%，至少16px边距、双向居中，面板调宽和窄屏时不越界；不覆盖全局MessageBox宽度。继续编辑/遮罩/Esc均保留输入，只有放弃修改才恢复原值并执行原定离开操作；默认聚焦继续编辑并限制确认期间Tab焦点。

品牌栏仅文献库改为52px，Logo 30px；窄屏保留品牌与个人资料/退出操作。上传成功、重复、失败通知在右下角约5秒自动消失（悬停暂停），支持手动关闭；成功/重复提供对应真实详情，网络/服务失败可重试原文件，无效/超限提供重新选择。通知不增加主列表上方高度，配置失败另保留可用重试入口。详细证据见[P2-A UI记录](../development/p2-a-ui.md)。

## P1 表单交互与统一主题

品牌主色正式确定为#9B0000；英文名Litera、中文名和左右分栏保持不变。共享Token在frontend/src/theme.css集中定义：

| 语义 | Token | 色值 |
| --- | --- | --- |
| Primary | --litera-primary | #9B0000 |
| Hover | --litera-primary-hover | #B82A2A |
| Active | --litera-primary-active | #750000 |
| 浅红背景 | --litera-primary-soft | #FFF4F4 |
| 页面背景 | --litera-page | #F7F8FA |
| 卡片背景 | --litera-card | #FFFFFF |

--brand-primary、--page-bg、--surface为兼容别名。Element Plus的primary、light-3、dark-2分别引用Primary、Hover、Active，其余浅色由主色混合白色得到；错误/成功/警告使用独立语义色。运行时Logo采用内联SVG的currentColor引用主题；静态favicon只用与Primary一致的默认回退值。按钮、链接、标签、焦点和其他页面品牌强调共用Token，不在组件中重复写色值。

| 操作 | 行为 |
| --- | --- |
| 首次进入、聚焦 | 不进行校验、不显示错误 |
| 输入过程中 | 不频繁校验；修改已有错误字段时清除对应提示 |
| 尚未提交时空值失焦 | 保持正常；必填错误在提交时检查 |
| 非空值失焦 | 用Element Plus validateField检查当前格式 |
| 点击提交 | 原生表单统一校验必填项/格式/密码确认，非法请求不发往API |
| 切换登录/注册 | 关闭规则变化自动校验，在下一次渲染后clearValidate；清空密码/确认及过时服务端错误 |

不降低邮箱、密码8–128字符、显示名称1–80字符和确认密码规则，不改变后端认证、Cookie/CSRF/Origin逻辑。修改密码后清除过时确认提示，下一次失焦/提交再核对。
