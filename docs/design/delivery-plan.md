## 页面验收

P1：Litera 品牌；登录/注册表单切换；字段校验、重复邮箱、无效凭证/网络失败提示；密码只以哈希入库；登录路由到 /library（尚未交付库时明确阶段提示，不模拟列表）；刷新保持有效会话；退出/过期后受保护 API 401；普通用户资料可更新；无管理员/第三方/短信登录。

P2：截图对应顶部、导航、中央表格、分页；上传本人 PDF 后真实落库落盘，浏览器查看/下载返回原字节；同用户重复含回收站被提示；标题/作者可手工修改；搜索、标签全部匹配、年份/文件夹筛选与排序；文件夹/标签 CRUD；软删除在库不可见、回收站恢复、永久删除失败不误报；最近打开记录可排序；导航折叠保留图标、拖动和窗口变化中央区自适应。未实现导入不出现假功能，parseStatus=not_requested。

P3：三种互斥视图/50%–500%缩放；缩略图/Outline/真实文本搜索、无文本不OCR；全部13类对象、颜色/属性/删除、撤销重做与持久化一致；进度跨刷新；多标签独立、关闭不丢草稿；右区搜索/列表、左右可收起调宽/窄屏抽屉；原件保真与全类型第三方可见导出。没有03–06业务UI、机器人或模拟工作区。逐阶段主要交付物/用户验收及每项验证见[02 tasks](../../openspec/changes/02-pdf-reader/tasks.md)。

## 测试策略

后续实现使用 pytest 做服务/权限/文件失败测试，MySQL 临时测试数据库验证真实约束与迁移；前端建议 Vitest + Vue Test Utils 做表单/状态/事件测试，Playwright 做 P1→P2→P3 端到端测试。接口测试通过实际 HTTP 校验状态码、包络、Cookie/CSRF、multipart 与 Range。具体依赖版本在相应阶段锁定。

每个任务组同步补其测试与接口说明，不积压到末尾。测试数据包括两普通用户、同字节重复 PDF、不同页尺寸/旋转 PDF、多页选区、无目录 PDF、无文本扫描 PDF、非法文件、网络/磁盘失败；不在仓库提交含敏感信息的文献。外部供应商适配器单测可替身验证失败，验收演示使用真实结果并明确供应商环境，不用 mock 页面宣称开发完成。

重点整体验收：跨用户全部读写/关联/内容/作业拒绝；CSRF 和过期会话拒绝；数据库失败无可用孤儿记录；重复上传并发不多建文献；软删除期间派生请求不可用；页面切换取消旧请求；05 版本变化与 06 引用一致；03/06→04 来源真实关联。性能指标待目标并发、文件大小与模型确定后写入相应 change，当前不凭空承诺延迟。
