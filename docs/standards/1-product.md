## 用户、场景与页面

产品用户为需要管理和阅读科研 PDF 的普通账号；本期无教师/管理员/跨用户共享角色。团队协作开发不等于用户共享数据。[README 用户与场景](../../README.md#用户与场景)为摘要，以下清单为页面级核对表。

| 页面/入口 | 角色与触发场景 | 当前状态 |
| --- | --- | --- |
| `/login`、`/register` | 访客注册、登录；注册成功后自行登录 | 现有 AuthPage |
| `/library` | 本人导入/检索/分类/手工编辑题录、最近阅读、回收站 | 现有 LibraryPage；这些是页面内视图，不另造路由 |
| `/reader/:documentId` | 本人阅读、搜索、批注、导出；从选区翻译或保存笔记并回查来源 | 现有 ReaderPage；翻译/笔记是面板，不造 `/notes` 或 `/translate` 假页面 |
| `/profile` | 本人查看/修改个人资料、修改密码 | 现有 ProfilePage；改密码后全部本人会话失效 |
| `/settings/ai` | 本人配置/测试/删除个人模型 | 页面现有；服务端开关和 Vault 决定是否可用 |
| `/`、未知前端路径 | 回到文献库；受保护路由未登录转登录页 | 现有 router.ts；未知 API 保持错误，不能回退 HTML |
| 05/06 未来能力 | 自动提取候选、文献问答/引用 | 未接入；先写对应 OpenSpec 场景及入口，不添加假结果 |

## 术语表

| 面向用户 | 对应字段/代码 | 不混用的含义 |
| --- | --- | --- |
| 文献 | Document / documentId | 文献是管理记录；PDF是附件，不能将二者删除语义混为一谈 |
| PDF 原始文件 | DocumentFile / attachment | “导出带批注PDF”是新产物，不是改写原件 |
| 批注 | annotations | 阅读器标记/形状/插入对象；不同于独立的笔记正文 |
| 笔记 | Note / noteId | 一条笔记可关联多篇文献；解除关联不等于删除笔记 |
| 来源摘录、查看原文 | sources / source | 有文献ID、PDF哈希、物理页；缺范围时仅跳页，不编造高亮 |
| 原文、译文、上一条译文 | originalText / translatedText | 选区变化后历史结果不得标为当前选区 |
| PDF 第 N 页 | pageNumber | 从1起的物理页，不是论文印刷页号 |
| 我的模型、后端默认模型、隔离Mock | user / developer / mock | 配置来源不同；Mock必须明确非真实结果 |
| 最近阅读、回收站 | reading-history / trash | 列表/软删除视图，不等于永久删除 |

## 响应式核对矩阵

| 宽度 | 预期/检查 |
| --- | --- |
| 390、768px | 控件可达，文献表可在容器内滚动；翻译/笔记使用窄屏面板，不能挡住关闭和保存入口 |
| 1280px | 检查1100–1499区间浮动面板与阅读区，打开/关闭后恢复阅读位置和焦点 |
| 1600px | 检查宽屏布局、面板折叠/拖宽、长标题、关联文献集合与多标签 |

现有样式存在1099/1499等功能断点，本矩阵是核对样本，不要求本次重写CSS。浏览器基线为实际验收的Chrome/Edge版本；仅Chromium内核名称不能证明PDF.js兼容，记录具体版本。联想浏览器失败已知，未承诺兼容。
