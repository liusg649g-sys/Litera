## 首轮实现（历史）

- 移除插入工具栏的资产管理按钮、维护面板及专用样式；更新取消图片后的清理提示，避免引导到已移除入口。
- 图片/视觉签名正常加载时仅显示“更换图片”；加载失败才显示原因和“重试加载图片”。
- 重试期间显示“加载中…”并禁用重复点击；成功后恢复显示并收起重试，失败可再次重试。
- 重试按assetId递增请求版本，只重新请求该资产，不保存批注或覆盖透明度等编辑草稿。
- 受保护的上传/读取/状态查询/清理API及台账保留。后台启动/每60秒扫描到期资产；未引用上传1小时回收、已删对象24小时撤销租约保持不变。
- 未改后端代码/数据库/业务数据/原始PDF，不运行Docker，不提交/推送/sync/archive。

## 用户手动更新

本轮仅需重建前端（若尚未部署上轮修改密码，仍需同时更新api）：

```cmd
docker compose up -d --build --no-deps --wait nginx
```

Ctrl+F5后检查插入栏与图片属性框：正常及加载失败时均无重新读取/重试加载按钮，只保留更换图片。最终UI体验待用户验收。
