# 选区右键快捷批注（2026-10-20）

用户授权新增类似Word的文本选区右键面板，仅包含高亮、下划线、波浪线、删除线、注释；鼠标在面板上保持显示，离开后约50px距离逐渐淡出。

## 实现

- 新增PdfSelectionToolbar，复用既有AnnotationToolIcon、createFromSelection、真实Range/逐页坐标采集及当前颜色；四标记自动入原串行CAS保存，注释进入既有右侧卡片确认/取消。不增加自由文本/手绘工具，不改13类对象或主工具栏。
- 阅读组或批注组均可对真实选区右键；成功创建后切到批注组。有未完成编辑/签名/插入/上传或活动绘制工具时不打开面板。
- 面板贴近实际右键所在选中行，优先上方，空间不足下方避让；限制在阅读区域与屏幕内。长跨页选择不定位到远离鼠标的首行。
- 按距面板边缘的欧氏距离映射opacity=max(0,1-distance/50)，50px关闭；面板内悬停保持1，键盘焦点位于栏内保持可操作。70ms短过渡只平滑透明度，不采用定时隐藏。
- 按钮pointerdown防止焦点默认行为破坏原选区；仅有效选中文字右键阻止原菜单，普通右键保留浏览器菜单。Shift+F10可打开并聚焦首工具，Enter操作，Esc关闭。
- 选区改变/滚动/窗口resize/失焦/禁用/切文献及卸载关闭；销毁移除全部监听。局部revision拒绝过期定位，沿用原generation拒绝过期文献创建。
- 面板在阅读器root内，原生全屏正常显示；颜色、图标、白灰主题及北大红沿用。无新API、数据库、迁移或依赖，不改原件，不运行Docker或操作业务数据。
