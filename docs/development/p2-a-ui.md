日期：2026-10-14。Change：01-literature-management。仅修改前端UI/交互及对应规约文档，不启动P2-B，不改后端规则、API或数据库。

## 参考与修改

已读取docs/references/xiaolvjing/06.png、07.png、08.png。只参考紧凑单行表格、更多菜单与右侧信息栏的交互，不复刻品牌/会员/商业入口或未实现业务。

- 主列固定为原文标题、作者、发表年份、期刊、标签、操作；原文标题占更多宽度。文本单行省略，超宽时统一白色浅灰边框Element Plus Tooltip，无原生title；保留横向滚动和固定右侧操作列，表头约44px、行约48px，无列设置。
- 行操作为阅读/详情/更多。阅读是既有浏览器PDF预览，并提示在线阅读器待实现。点击式Element Plus Dropdown仅提供编辑题录信息/下载PDF，传送body避免裁切，外部点击关闭。
- 原题录表单与GET/PATCH复用到DocumentInfoPanel。单一面板切换文献，旧响应不覆盖新文献；包含题名、作者、年份、期刊、DOI、摘要、关键词、标签、文件大小/名称/上传时间，空值统一未填写。
- 面板默认360px，320–520px拖动/键盘调宽；桌面挤占右侧布局，中央至少560px，关闭恢复表格。剩余区域不足320+560时改覆盖抽屉，同一组件保留草稿；背景inert、焦点约束、Escape/背景关闭、关闭后恢复入口焦点。
- 编辑保存仍走版本CAS，成功同步真实列表，失败保留草稿。关闭/切换/取消编辑/普通路由离开先确认未保存修改；浏览器刷新有离页保护。保存时禁关闭；会话失效仍回登录，不用草稿确认阻断认证退出。
- 右下角Element Plus通知约5秒消失（悬停暂停），可手动关闭。成功查看文献，重复查看已有文献；网络/服务失败重试原文件，无效/超限重新选择。通知不占列表上方空间。
- 仅文献库品牌栏压至52px，Logo 30px，保留Litera与#9B0000 Token；登录/注册/资料样式不改。

## 实际体验步骤

### 局部确认修复

未保存确认原来调用ElMessageBox并挂载页面级遮罩；其默认width:100%依赖420px最大宽度，而library-confirm又将max-width覆盖成视口宽度，导致确认几乎横跨页面。已改为DocumentInfoPanel内部的局部浮层，遮罩仅覆盖面板，确认卡宽88%且至少留16px边距，水平/垂直居中，随面板调宽或转窄屏抽屉重新布局；未修改任何全局MessageBox样式。

继续编辑、局部遮罩点击及Esc均返回false并保留全部输入；放弃修改恢复载入数据并返回true，沿用原有关闭/切换/取消逻辑。浮层默认聚焦继续编辑，约束Tab焦点，拖动分隔条后Esc仍取消确认。后端/API/数据库不变。构建与单元10/10通过，完整浏览器12/12；最终键盘边界修复后相关4/4回归通过，覆盖五种路径、全部字段保留、恢复原值、不写入数据库、调宽和窄屏居中。截图library-confirm-local.png及library-confirm-local-mobile.png为临时验收产物。

由用户手动重新构建部署后，在文献库体验：

1. 上传PDF，确认通知在右下角且不挤动表格；点击查看文献、重复上传查看已有文献，验证手动关闭和约5秒消失。
2. 在长标题/作者/期刊上悬停或聚焦，检查单行省略与浅色Tooltip；表格横向滚动时操作列保持右侧。
3. 点击更多，确认只有编辑题录信息/下载PDF；点击外部关闭，阅读使用真实浏览器PDF预览。
4. 点击详情，检查表格缩小、默认360px面板、信息分组及拖动调宽；切换文献只有一份面板，关闭恢复空间。
5. 编辑后先尝试关闭/切换/个人资料，选择继续编辑应保留草稿，选择放弃才离开；保存后表格与刷新数据一致。
6. 缩小窗口，检查同一草稿保留、覆盖抽屉可滚动、Escape/背景关闭确认及键盘操作。确认没有新增标签/分类/检索/回收站业务。
