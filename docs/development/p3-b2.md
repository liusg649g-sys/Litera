- 签名使用工具栏下方轻量手写画布，支持清空、取消和PNG/JPEG导入；确认后上传透明PNG并在PDF中跟随鼠标放置。图片上传校验完成后，同样移动预览、点击放置、调整后保存。取消未引用资产立即请求清理；上传中可取消请求，30秒超时保留本地文件供重试，失败文件未明确取消前阻止切文献。未知结果的上传仍由服务器台账与后续扫描回收。退出/换账号清除私有预览与本地文件引用。

- 编辑中保留轻量选框/必要控制点；保存/取消、空白点击（无编辑会话）、Esc、退出工具组清理无用选中反馈。正文输入/属性控件使用自身键盘操作，阅读模式保留PDF原文选择和复制。

## 资产、数据及生命周期

迁移链新增 `0006_reader_assets`（接 `0005_annotations`），只创建 `reader_assets` 和索引，不重建原业务表，不修改账号、documentId、题录、原PDF存储键或进度。资产继续使用API专用私有PDF卷，内部独立受限文件名，任何DTO不暴露存储路径。

Pillow 12.0.0 固定依赖；忽略浏览器声明的MIME，先识别PNG/JPEG、verify结构、再load完整解码，拒绝SVG、其他格式、多帧、损坏或截断图片。EXIF朝向规范化，重新编码并去除源元数据；PNG保留透明通道并记录规范化字节SHA-256；引用通过真实annotations反查，不维护易失配的客户端计数。文件与请求流均有限额，解码在工作线程中进行。

| 资源 | 限额/规则 |
| --- | --- |
| 输入及规范化后的单资产 | 5MiB |
| 真实解码尺寸 | 20,000,000像素；单边≤16384 |
| 每篇未清理资产合计 | 50MiB（包括待清理文件） |
| 单笔手绘 | 10,000点 / 60秒 / 100,000屏幕像素路径；超限明确取消整笔，不静默截断 |
| 单对象JSON/正文 | 1MiB / 20,000字符；水印UI≤200字符 |
| 单篇活动对象 | 10,000个 |
| 笔宽/字号/不透明度 | 0.25–20pt / 6–144pt / (0,1]，UI步长按原控件 |
| 未引用上传 | 1小时租约 |
| 删除或更换图片后的资产 | 最后活动引用消失后保留24小时供撤销 |
| 收据/撤销栈 | 原24小时收据；每篇最多100条、不跨刷新 |

上传先将 `uploading` 台账提交，再写文件，成功改 `ready`；磁盘异常或进程中止留下可扫描的台账。清理先持久化 `cleaning`/attempts，文件缺失视作已删，失败改 `failed`/errorCode，再次删除幂等重试。API启动及每60秒扫描到期资产；文献和资产锁与批注命令协调，活动引用不回收。清理成功保留 `deleted` 台账，不再计配额。

所有上传/读取/关联/清理逐次校验会话、用户和文献双重归属；写入要求Origin/CSRF。错用户/错文献404，已知但失效资产422，引用中或撤销租约未到期的显式清理409。关联资产及更新标注/集合CAS/收据在同一事务中进行。上传写文件前再次核对台账仍为uploading，防止清理后迟到写入复活资产；扩展水印角度仍将零角度序列化为原B1整数0，保留旧命令收据指纹。删除后超过租约的资产恢复会明确失败，草稿保留，不伪造图片。

文献软删除隐藏访问但保留对象和资产，恢复同ID；永久删除使用原cleanup_jobs，逐个删除资产后再删除关联记录/PDF。文件或数据库清理失败返回202及可查询作业，用户重试继续；不会把202当成功。导出快照租约属于未实施的C1，本阶段没有导出接口。

## 用户反馈：七类新增对象无法用橡皮擦删除（2026-10-16）

排查结果：手绘ink、矩形rectangle、圆形circle、椭圆ellipse、签名signature、水印watermark、图片image共用PdfDrawingObjects。ReaderPage.selectAnnotation已将非阅读组的erase点击接入原annotations.remove，列表/工具栏/Delete键和后端通用删除也已接入；遗漏发生在对象覆盖层：active仅在enabled且tool为空时成立，CSS只允许active对象接收鼠标，切erase后对象命中全部关闭。因此七类均受影响，并非缺少后端DELETE或资产删除接口。

局部修复：PdfDrawingObjects新增独立erasing状态（非阅读、erase、没有未确认编辑），reader.css仅为该状态开启对象visiblePainted命中。擦除不复用active，避免擦除时触发移动、显示缩放控制点或越过编辑保护；阅读模式继续pointer-events:none。命中仍只删除整个Litera对象，空心形状点击描边；不擦原PDF、不即时删除被引用资产。原队列、CAS/commandId、墓碑恢复及资产租约机制保持不变，未改后端、接口或迁移。
