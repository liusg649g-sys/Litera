## 实现

- 缩放：主栏加减25个百分点、百分比手输（支持小数）、50/75/100/125/150/200/300/400/500预设和适应宽度/高度。非数保留输入并提示，越界限制到50%–500%；fit同样受此范围限制。双页总宽+20px间距/最大高度参与计算。仅PDF区域非passive Ctrl+wheel；ResizeObserver监听实际阅读区域，面板开关/拖动/窗口变化重新计算fit。保持中心或鼠标处页内锚点，显式跳页优先于异步布局恢复。
- 页面仍用同一PdfPage，共享逻辑scale/viewport的Canvas、TextLayer、搜索临时覆盖层和未来reader-object-layer。100ms稳定重绘、取消旧generation、临时Canvas完整帧提交；DPR最多2、单页16M像素及单边8192像素保护，必要时降低backing分辨率而逻辑倍率仍可500%。离屏Canvas/text释放，缩放不会留下远页旧缓冲。
- 左侧复用原可折叠/180–320px调宽栏。真实128px宽缩略图仅渲染可见附近150px，离屏清零，当前页红框/点击跳页，无独立滑块。Outline来自PDF，层级展开/折叠，解析命名及显式内部目标；支持XYZ/Fit/FitB/FitH/FitBH/FitV/FitBV/FitR位置，无大纲明确空状态，坏目标/外部动作只给错误反馈。
- 搜索复用原右面板。逐页读取PDF.js真实文本，无OCR/05调用；NFKC及空白统一，保留UTF-16字符到text item和offset映射，支持跨item、大小写、全词、序号/数量、上下循环与结果点击定位。全词采用浏览器`Intl.Segmenter('und', {granularity:'word'})`的Unicode词边界；英文按整词、中文按词分段。高亮只在临时搜索层，清空即移除，不写批注。无文本、混合文本/图像页、无结果、搜索中进度均明确；改词/切文献废弃旧任务结果。
- 搜索逐页处理后释放文本引用，不保存全篇文本索引；初始保护为单页50万UTF-16字符、全文2万匹配。超过限制明确报错要求更具体查询，不静默截断后声称完整。长文索引/压力优化留C2。
- 阅读进度首次GET恢复页码/倍率/模式，首目标页完整成功后才CAS记录真正打开。1秒防抖、持续变化最多5秒一次、每文献串行请求、8秒超时、离开主动flush；以loadedDocumentId及generation隔离快速切换的状态。失败保留本地设置草稿，显示重试并阻止静默离开；若PDF本身加载失败则保留草稿并允许返回库，草稿重放必须等待真实首目标帧成功；409读取最新版本，明确选择载入服务端或保存本地。sessionStorage按用户/文献隔离，刷新提示处理，退出/换账号清理；不存PDF字节或选中文本。
- 公共上下文为真实`ReaderContext`/`SelectionPosition`，含documentId、选区起始物理页、selectedText、每页textQuote与未旋转CropBox归一化rects、单调contextRevision。可取消订阅，提供context-change/selection-change/document-change/context-cleared及同名`litera:reader:*` DOM事件；取消选区/切文献/离开正确清空。NoteDraft/Citation仅类型，不实现03–06服务或UI。

## API 与迁移

`0004_reader_progress`接`0003_library`，仅在原reading_progress新增nullable VARCHAR(16) `view_mode`、`zoom_mode`，没有重建表、删除数据或修改PDF。后续成员从0004 head串行协调新编号。升级旧null读取默认continuous/fit-width，原page_number/字符串zoom/last_read_at/version保留。

GET/PUT `/api/v1/documents/{id}/progress`沿用Cookie/Origin/CSRF/owner/软删校验。新增参数viewMode、zoomMode及严格boolean recordOpen（缺省true兼容旧打开请求）。任何非空状态写和recordOpen=false必须带独立progress.version，未读0、陈旧409；pageNumber为真实PDF范围内整数，zoom为0.5–5有限数，新模式显式null/非法值422。旧PUT {}及旧null pageNumber/zoom仅记打开，不清已有状态。recordOpen=true更新服务器最近打开时间；A2后续自动保存false不改变最近打开时间，下载/GET不记阅读。

文献行写锁串行化首次进度创建，再用progress FOR UPDATE当前读检查版本，避免MySQL REPEATABLE READ旧快照绕过CAS。复用pypdf按需验证/缓存原PDF物理页数，不改变题录version，不调用Change 05。详见[API契约](../design/api-contracts.md)、[模型](../design/data-model.md)。

## 手动验收清单

1. 登录原账号，打开原有PDF。输入50/500、超界10/900、非法文本和小数；加减/预设/fit-width/fit-height，三视图检查页码/位置、双页总宽及奇数尾页。PDF内Ctrl+滚轮缩放，其他区域保持正常；展开/收起/拖动左栏及搜索面板，fit随阅读区更新，不突然跳页。
2. 展开缩略图，滚动长文确认按需真实绘制、当前页高亮，点击第N页跳转。切大纲，验证多级展开/折叠、目录位置；无目录明确空状态，坏目标明确反馈。
3. 在右搜索面板查真实正文，切大小写/全词、上下匹配/点击结果，确认临时黄色/橙色覆盖原文；清空无残留。扫描页提示无文本，混合文件只搜文本页。快速改词/切文献无旧结果串用。
4. 选择真实文字并复制，三模式和旋转页选择正常。更改页码/倍率/模式，等底栏同步后刷新恢复；回库打开第二篇，再切标签，各自恢复。只下载原件不改变最近阅读。
5. 两个浏览器会话打开同篇，分别改进度，确认陈旧端明确冲突、保留本地并可选择服务端/本地。开发者工具阻断PUT progress，确认失败提示/重试、离开保护；强制刷新后仍可处理本地待存设置。恢复网络后同步，再检查另一用户无法访问本篇。
6. 回归标签拖动、标题Tooltip、工具组收起/展开、左栏180–320px及窄屏、原件下载、库中上传/题录/分类/检索/回收站。批注/形状/插入/导出仍明确开发中，不应创建任何对象。
