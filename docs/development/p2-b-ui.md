## 原因与实际调整

此前更多菜单直接进入完整题录编辑，原生select与Element Plus外观不一致，分类fieldset和纵列复选框使操作冗长；关键词只在提交时检索，零结果只按rows.length判断，导致非空库也提示首次上传。

- DocumentClassifyDialog.vue复用420px LibraryActionDialog，真实GET载入当前文献/文件夹/标签；移动可选未分类，标签多选，只有标签选项局部滚动。取消/Esc/遮罩不写入；仅PATCH version+folderId或tagIds，不重复另一套业务接口。失败保留选择；409可加载最新版本保留选择后重试。
- LibraryPage.vue成功同步列表及同篇已打开信息面板；DocumentInfoPanel.sync更新DTO与基线，完整编辑仍可直接修改分类。已有草稿先按面板内确认继续/放弃，保存中阻止离开，其他文献面板不被替换。
- 文献库排序/方向/文件夹筛选/每页数量、面板及快捷窗口统一ElSelect/Option，菜单teleport到body，局部白灰/红色样式；空字符串作为未分类/全部文件夹显式保留，避免被组件空值策略显示成Select。原本为原生输入定义的CSS排除组件内部输入，标签使用CheckboxGroup同行/横向换行，取消外层分类框。
- 关键词及筛选变化300ms debounce，分页回1；立即abort旧请求并递增revision防过时响应。更新保留最后一次结果和轻量状态，初次/换视图使用完整加载；清空关键词保持文件夹/标签/年份/排序，辅助检索按钮仍可立即提交。
- 空结果必要时通过现有GET documents?pageSize=1查询未过滤total，依据最后完成的查询与真实总数区分空库、检索无匹配、空标签、空文件夹；仅真实空库提供首次本地上传，检索提供清除，分类提供回我的文献及现有移动/标签关联指引。空状态缩至紧凑180px，无从文献库导入接口。

## 手动体验重点

1. 更多→移动到文件夹直接显示小窗口，选择未分类或目标文件夹，取消应无变化，确定后表格/同篇面板同步。
2. 更多→管理标签显示已有标签勾选，多选保存或取消；数量多时只选项滚动。面板完整编辑分类仍可保存，草稿继续/放弃正常。
3. 输入关键词自动检索，快速替换不串结果，清空保留其他条件；排序/分页下拉均为同一主题且不会被表格/面板裁切。
4. 分别检查未导入空库、已有文献但检索无匹配、无关联标签、空文件夹；仅空库出现导入第一篇，其他按钮含义对应清除/返回归类。
5. 缩至360px，标签对齐、下拉、快捷窗口与完整面板可用，上传、回收站恢复继续正常。
