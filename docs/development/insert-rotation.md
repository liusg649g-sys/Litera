# 插入对象角度与签名操作（2026-10-20）

本次为用户实际验收反馈修正：水印角度可手动输入并明确显示当前值，最小调整单位1°；图片与视觉签名支持同样的旋转；签名的更换图片语义不清，用户允许直接删除，本轮选择删除该按钮。

## 实现及兼容

- 三类共用角度滑块与数值框，−90°～90°，1°步进，双向同步。小数输入取最近整数，越界夹取；清空时不写伪0，失焦恢复当前值。
- 水印保持已验收的按框显示与裁切方式；图片/签名以物理box中心顺时针旋转，选框和四角控制点随之转动。非方形页面仍按物理角度计算；缩放逆变换指针增量，保留比例与对角锚点。
- 使用既有geometry.rotation JSON，后端允许watermark/image/signature非零角度，其他box类型仍只能0；零角度保留原整数表示，既有收据/命令/CAS/撤销/草稿机制不变，无新迁移或依赖。
- PDF导出图片/签名同样围绕中心旋转，转换浏览器向下Y轴与PDF向上Y轴角度方向。原始PDF保持只读。
- 签名属性只有透明度/角度及取消保存，不提供更换图片或重新读取；签名原有创建方式保留。图片属性仍可更换图片。
