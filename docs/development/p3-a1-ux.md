## 根因与改动

- 标签store原已为模块级轻量状态，返回库时并未主动销毁；缺的是库页面的标签导航展示。抽出WorkspaceTabs供库/阅读器共用，文献管理入口回/library；路由决定PDF激活态，库中不误高亮。单个关闭同步状态，关闭活动标签先完成导航再移除，避免等待阅读记录期间把旧页面切回默认页。退出/换用户仍清私有状态，不保留PDF.js实例、字节或DOM，不做刷新持久化/批量关闭。
- 库标题直接进阅读器，保留省略/统一Tooltip。操作列为详情、受保护原始下载、更多（题录编辑/移动/管理标签/回收站），去掉重复阅读/菜单下载。回收站保留原恢复/删除。题录保存同步已有标签题名，库内软删除同时移除对应标签；原排序/分页/分类和草稿保护继续沿用。
- 折叠导航使用同一可见Tooltip状态，切换立即隐藏旧提示、离开100ms收起，常规/文件夹均统一浅色右侧提示；展开禁用冗余提示，折叠文件夹区增加浅灰分隔线。
- 主工具组为阅读/批注/形状/插入，默认阅读无二级栏；其他组显示现有开发中预留。布局变更保留页内锚点、横向滚动和页码，回阅读清工具说明。搜索/列表/原件下载/导出为统一紧凑图标及浅色Tooltip，导出明确开发中，没有搜索/批注/导出业务请求；图标Tooltip采用视口fixed定位，避免窄屏横向工具栏返回焦点后撑宽页面。
- 原库侧栏指针捕获拖动提取为startPointerResize共同使用；阅读器左面板180–320px，键盘10px调宽，收起重开保留宽度，窄屏仍用原生dialog覆盖，不挤压页面。
- 原IntersectionObserver回调可能对已完成页再次render，造成清空/重复绘制；现只在可见性真正变化且未完成时渲染。图像页先在临时Canvas绘完整帧再提交，临时画布在完成/取消后清零；远处页照常释放。移除中央文字，页尺寸浅色占位/右上轻量指示；真实失败仍由原错误/重试处理，不显示其他文献旧帧。A1仍固定scale=1，没有提前开发缩放。

## 最近阅读：本轮明确授权的打开子集

上一轮A1按当时边界不调用recordOpen，故最近阅读为空。此次在首个真实PdfPage完整ready后，每文献加载generation自动尝试一次现有PUT /documents/{id}/progress，正文仅{}，使用既有Cookie/Origin/CSRF。后端仍用服务器时间写lastReadAt，复用原记录/历史排序，不创建新接口/字段，不提交页码、倍率或视图。

离开/切文献等待已经发出的打开写入结束（8秒超时），避免库先查询旧历史。失败用可重试提示和console.warn结构化documentId/status/code/requestId诊断，不写前端假记录；成功后模式/工具切换不会重复自动写。纯下载、题录查看、首帧未成功均不记阅读。完整进度持久化仍A2。

## 手动验收

已有服务可只重建前端，原API/数据库不动：

```cmd
rem 在项目根目录执行
docker compose up -d --build --no-deps --wait nginx
```

Ctrl+F5后登录：点击库标题进入阅读器，默认阅读无二级栏；切工具组并开关/拖动导航；选择复制真实文字，检查三视图/页码与图标提示。点击文献管理回库，确认顶栏标签保留/最近阅读更新；打开另一篇后用标签切换，依次关闭至库恢复正常。详情只开原信息面板，下载仅原件，回收站不阅读。无需重传PDF或重建数据库。

## 标签栏定向补充

范围仅WorkspaceTabs及reader/state.ts的重排函数，不修改通用OverflowText、PDF加载/渲染、路由、阅读记录API或其他页面布局。原Tooltip使用通用200ms显示延迟和默认过渡，现以单一可见ID与100ms显示/隐藏定时器控制，沿用Element Plus浅色library-popover，禁用额外过渡；只为省略标题提示，快速切换立即隐藏旧提示，拖动/卸载清理提示与计时器。

不增加拖拽依赖，使用Pointer Events。标题鼠标按下后水平位移至少6px且大于纵向位移才捕获指针，关闭按钮不参加；拖动时原标签轻微透明、目标插入线，横向溢出边缘自动滚动，文献管理sticky固定。松手才按其他标签中点决定beforeId并重排原有对象；没有路由或业务请求，不改page/mode/scrollTop或PDF实例。Esc、指针取消、失焦及卸载清理监听/动画帧并取消；防止拖动结束生成的click切换文献，下一次真实点击不受延迟限制。顺序仍由库/阅读器共享，不要求刷新保留，不开发C2批量关闭等能力。
