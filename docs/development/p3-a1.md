# P3-A1 PDF阅读器基础版本

日期：2026-10-15。范围仅Change 02 tasks 1.1–1.6，A2/B1/B2/C1/C2均未实施；用户实际体验验收待完成。没有运行Docker Compose、变更业务数据库或提交/推送/归档。

## 实现与依赖

- `pdfjs-dist`精确锁定6.4.299，官方npm稳定版，要求Node >=22.13或>=24；本机Node24.15.0，沿用现有Node24容器构建。package-lock更新，npm安装审计0漏洞。
- `reader/pdf.ts`以同包`build/pdf.worker.min.mjs?url`创建真实module Worker，并用PDFWorker.create({port})传入，禁止fake worker回退。Worker启动错误、文档加载/销毁、文本层全局清理集中管理。
- Vite插件从已安装同版包读取CMap、标准字体、WASM及ICC：开发同源中间件，生产emit到`/pdfjs/6.4.299/`；Worker为带hash构建资源，无第三方CDN。使用同版pdf_viewer.css文本层样式。依据[PDF.js官方API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)及实际包类型/API验证。
- `ReaderPage.vue`负责路由文献切换、metadata/content加载、generation旧响应隔离、三模式/页码、工具栏、轻量标签、左右面板；`PdfPage.vue`复用Canvas/text layer及共享viewport，空交互覆盖层不抢文本选择；`ReaderPanel.vue`桌面aside、窄屏原生dialog提供焦点约束/Escape及焦点恢复。
- `reader/state.ts`只保留documentId/title/page/mode/scrollTop等会话状态与坐标转换，不保留PDF实例/字节/页面DOM。返回文献库后可再打开另一篇并切标签；当前标签可关闭，完整批量关闭/溢出管理留C2。退出/会话失效/用户身份变动清理私有标签。

## 实际行为与接口

- 文献库阅读现在进入`/reader/:documentId`受保护路由，不再新开浏览器预览。复用GET文献详情及同源受保护content（HttpOnly Cookie）；保留原件download=true。没有新增后端业务API或迁移，认证/owner/回收站规则不变。
- A1不调用recordOpen或PUT progress，不记录点击已读，不存跨刷新页码/视图。原01进度API及已有记录保留；成功渲染后的真实进度/最近阅读接入留A2。
- 三种视图共用PdfPage：连续纵向，单页切换，双页按1/2、3/4分组翻组，奇数尾页单独显示；输入页码范围校验，单页/双页在视口聚焦时方向键切页/组，输入框不接管。
- 当前使用PDF.js scale=1固定阅读尺寸，可在PDF容器内部滚动。交互缩放/适应宽高/Ctrl+wheel、缩略图/Outline/搜索均属A2，明确显示阶段说明。
- 批注/形状/插入二级栏含图标/名称/颜色预留。未完成控件标注开发中，点击只反馈说明，不写对象、保存、导出或其他业务数据；无翻译、笔记或AI工作区。
- 401触发现有失效事件并回登录，404提示不存在/删除/无权访问；416最多一次关闭Range/Stream的完整读取重试；网络/损坏/加密文件错误有重试/返回。切换先卸载页面取消render/text，再销毁旧文档/Worker，不向新文献注入旧结果。

## 资源与边界

连续列表保留轻量页占位，用IntersectionObserver仅渲染可见页及上下500px附近；离开范围取消任务、cleanup并把Canvas宽高置0。未渲染Canvas初始为0，防止浏览器默认300×150缓冲驻留。DPR上限初值2、单页像素预算16M；各数值是可实测调整的初始预算。没有提前实现分块渲染、复杂LRU/全篇索引或1000页压力优化。

坐标适配以未旋转CropBox左上角归一化，PDF.js viewport负责固有旋转/UserUnit/裁剪偏移，DPR只作用Canvas像素；没有标注CRUD或真实覆盖对象。

已有.env无需重建配置：

```cmd
cd /d D:\PKU\Projects\Litera

docker compose ps
```

1. 访问http://localhost:8080/login，登录并上传自己的合法PDF，列表点击阅读，应进入Litera阅读器。
2. 鼠标选择真实文字并Ctrl+C复制；切换三模式，输入页码、上一页/下一页，确认双页1/2首组与奇数末页。
